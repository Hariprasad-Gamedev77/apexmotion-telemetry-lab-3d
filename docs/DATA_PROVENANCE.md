## 1. Core Principles of Data Provenance

To guarantee scientific defensibility and professional credibility, **ApexMotion Telemetry Lab 3D** adheres to four non-negotiable data integrity principles:

1. **Explicit Source Tagging**: Every telemetry datum rendered in the UI or processed by the analysis pipeline carries an unmodifiable provenance identifier.
2. **Strict Prohibition on Silent Fallback**: If a live UDP simulator feed disconnects or an external API is unreachable, the system displays an explicit disconnected state. It **never** silently replaces live simulator data with synthetic or mock data.
3. **Strict Prohibition on Silent Repair**: Ingested files containing non-monotonic timestamps, missing channels, or corrupted values trigger visible validation reports. Data is never quietly smoothed or synthesized.
4. **Transparent Synthetic Labeling**: Synthetic data generated by the physics engine is clearly labeled as `SYNTHETIC_SIMULATION` with yellow/amber UI indicators.

Every active session and telemetry packet carries the following metadata envelope:


## 3. Data Transformations & Traceability

### 3.1 Permitted Mathematical Transformations
The following transformations are permitted because they are deterministic and reversible:
- **Unit Conversions:**
  - Speed: $v_{\text{kph}} = 3.6 \cdot v_{\text{mps}}$
  - Throttle / Brake: Percentage $P_{\%} = 100 \cdot P_{\text{norm}}$
  - Radians to Degrees: $\theta_{\text{deg}} = \theta_{\text{rad}} \cdot \frac{180}{\pi}$
- **Coordinate Centering:**
  - Circuit survey control points are centered at origin $(0, 0, 0)$ via rigid translation without rotation or shear.
- **Harmonic Spatial Interpolation:**
  - Distance alignment to uniform $\Delta s = 1.0\text{ m}$ grids strictly within the convex hull of recorded data ($s \in [s_{\min}, s_{\max}]$).

### 3.2 Prohibited Transformations
- Extrapolation outside the minimum and maximum recorded distance.
- Polynomial smoothing across missing data gaps exceeding $150\text{ m}$.
- Silent substitution of missing channels with fixed constants without user notification.
